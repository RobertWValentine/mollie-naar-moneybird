# Beveiliging

Dit programma schrijft in een boekhouding en werkt met API-tokens van Mollie en Moneybird. Een kwetsbaarheid meld je daarom privé, niet in een openbaar issue.

**Melden:** via het tabblad **Security** van deze repo, knop **Report a vulnerability**. Alleen de beheerder ziet de melding.

Zet in de melding wat je zag, hoe je het kunt nadoen en welke versie je gebruikt. Plak nooit een echt token of echte boekhoudgegevens.

**Ondersteunde versie:** alleen de nieuwste release krijgt fixes.

Dit is een project van één persoon, aangeboden zoals het is. Een melding wordt gelezen, maar er is geen vaste reactietermijn.

---

**Reporting a vulnerability:** use the **Security** tab, **Report a vulnerability**. Please do not open a public issue. Only the latest release receives fixes.
